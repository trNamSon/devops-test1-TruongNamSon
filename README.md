
# DevOps Test 1 - Truong Nam Son

## Giới thiệu
Website tĩnh minh họa quy trình CI/CD sử dụng GitHub, Jenkins,
Vercel và Telegram.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- Git và GitHub
- Jenkins Pipeline
- Vercel CLI
- Telegram Bot API

## Quy trình CI/CD
1. Developer push code lên branch main.
2. GitHub webhook kích hoạt Jenkins.
3. Jenkins checkout source và kiểm tra các file.
4. Jenkins triển khai website lên Vercel.
5. Telegram gửi thông báo kết quả.

## Chạy website
Mở file index.html bằng trình duyệt.
